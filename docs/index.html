Documentação

Como a Nexora Forge funciona

Esta documentação descreve a arquitetura real do sistema: o que o agente pode fazer, onde o código executa e como o custo é controlado.

Como funciona

O ciclo é um loop de agente com ferramentas. Cada turno segue esta ordem:

  1. 1Você envia uma mensagem. O servidor valida a entrada e verifica seus créditos.
  2. 2O histórico da conversa é montado e enviado ao modelo junto com a definição das ferramentas.
  3. 3O modelo responde com texto e/ou chamadas de ferramenta.
  4. 4Cada chamada é executada na sandbox do seu projeto e o resultado volta ao modelo.
  5. 5O ciclo repete até o modelo não pedir mais ferramentas, com um limite de iterações.
  6. 6A resposta final é transmitida para a tela e o consumo de tokens é registrado.

Ferramentas disponíveis

O modelo só consegue agir através destas funções. Não existe execução arbitrária fora delas.

FerramentaO que faz
write_fileCria ou sobrescreve um arquivo, criando diretórios quando preciso.
read_fileLê um arquivo de texto da sandbox.
list_filesLista a árvore do projeto, ignorando node_modules e .git.
delete_fileRemove um arquivo ou diretório do projeto.
run_commandExecuta um comando de shell com timeout e captura de saída.
install_packageInstala dependências via npm ou pip dentro da sandbox.

Sandbox

Cada projeto roda em uma microVM isolada, com filesystem próprio e kernel próprio. O código gerado nunca executa no servidor da aplicação nem na sua máquina.

  • • Toda execução tem timeout — nada fica rodando indefinidamente.
  • • Sandboxes são encerradas ao fim da sessão ociosa.
  • • Um projeto não enxerga os arquivos nem a rede de outro.
  • • O preview é servido a partir da porta do dev server dentro da sandbox.

Chaves e cotas

Dois modos de uso, e você escolhe qual usar:

Cota gratuita

Mensagens contadas por dia no servidor, usando um modelo econômico. O conteúdo passa pelo tier gratuito do provedor, que pode usá-lo para melhorar os produtos.

Chave própria (BYOK)

Você cola sua chave do Gemini. Ela é cifrada com AES-256-GCM e nunca retorna ao navegador. Sem cota nossa e com a privacidade do tier pago.

Segurança

  • • Toda entrada de API é validada com Zod no servidor.
  • • Autorização verificada em cada rota: você só acessa seus próprios projetos.
  • • Segredos apenas em variáveis de ambiente, nunca no bundle do cliente.
  • • Comparações de segredo em tempo constante contra timing attacks.
  • • Rate limiting por conta e por IP nas rotas que consomem IA.
