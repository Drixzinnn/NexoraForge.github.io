Tool calling na prática: o loop do agente

Como montar o ciclo mensagem → ferramenta → resultado sem cair em loop infinito.

O loop do agente parece simples: o modelo pede uma ferramenta, você executa, devolve o resultado, e ele continua. Na prática, três detalhes decidem se funciona ou se trava.

Limite de iterações

Sem um teto, um modelo indeciso pode pedir ferramentas indefinidamente. Cada volta custa tokens. O limite precisa existir no código, não no prompt — o prompt pode ser ignorado.

for (let i = 0; i < MAX_ITERATIONS; i++) {
  const res = await model.generate({ contents, tools })
  if (!res.functionCalls?.length) return res.text
  const results = await Promise.all(
    res.functionCalls.map(call => executeTool(call))
  )
  contents.push({ role: "tool", parts: results })
}

Erro de ferramenta é informação

Quando um comando falha, não aborte o loop. Devolva o stderr ao modelo. Um agente que lê o próprio erro corrige; um que recebe silêncio repete o mesmo erro.

Streaming muda a percepção

Uma resposta de trinta segundos parece travada se o usuário vê a tela parada. Transmitir o texto enquanto é gerado, e mostrar cada ferramenta em execução, transforma a espera em progresso visível.
