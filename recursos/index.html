Recursos

Tudo que o agente faz, sem letra miúda

Esta é a lista real do que está implementado e do que está em construção. Cada item aqui corresponde a código no repositório — nada de promessa vazia.

Agente

  • Planejamento em etapas

    O pedido é decomposto em tarefas com plano visível antes de qualquer escrita de arquivo.

  • Tool calling nativo

    write_file, read_file, list_files, run_command, delete_file e install_package.

  • Streaming token a token

    Você vê a resposta sendo escrita, não espera o turno inteiro terminar.

  • Retomada de contexto

    Volte dias depois na mesma conversa: histórico e arquivos continuam lá.

  • Correção de erros

    Saída de comando e stack traces voltam ao modelo para corrigir na hora.

  • Múltiplas stacks

    HTML/CSS puro, React com Vite ou Next.js com App Router.

Execução

  • Sandbox microVM

    Isolamento real com kernel próprio: um projeto não vê os arquivos de outro.

  • Filesystem persistente

    Os arquivos ficam no projeto e são reabertos ao voltar, sem regenerar tudo.

  • Timeout obrigatório

    Toda execução tem limite de tempo. Sem sandbox esquecida queimando CPU.

  • Preview por porta

    O dev server sobe dentro da sandbox e é exibido em iframe isolado.

  • Instalação de pacotes

    npm, pip e afins rodam dentro da sandbox, nunca no servidor da aplicação.

  • Logs de execução

    stdout, stderr e código de saída visíveis para você e para o agente.

Integrações

  • GitHub

    Ler repositórios, criar branch, commitar e abrir pull request pela conversa.

  • Gmail

    Buscar e-mails para contexto e rascunhar respostas, com permissão explícita.

  • Chave própria (BYOK)

    Use sua chave do Gemini; ela é criptografada e nunca volta ao navegador.

  • Exportação

    Baixe o projeto em zip ou envie direto para um repositório novo.

Segurança e custo

  • Créditos no servidor

    Cota contada no backend. Burlar pelo navegador não é possível.

  • Rate limiting

    Limite por conta e por IP em todas as rotas que gastam dinheiro.

  • Teto de gasto global

    Se o custo mensal passar do valor definido, a cota gratuita bloqueia sozinha.

  • Validação com Zod

    Toda entrada de API é validada no servidor antes de tocar o banco.

  • Criptografia AES-256-GCM

    Chaves e tokens guardados cifrados, com autenticação contra adulteração.

  • Auditoria de consumo

    Tokens e custo por usuário e por dia, para você saber exatamente quem custa o quê.
