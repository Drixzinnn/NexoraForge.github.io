Tutorial

Como conectar suas APIs

Você tem duas opções: usar a chave do projeto (já configurada, com cota limitada) ou colocar a sua própria. Usar a sua é melhor — sem cota compartilhada, sem depender de ninguém, e no seu controle.

Usar a chave do projeto

Funciona imediatamente. Sujeita a rate limit compartilhado e ao teto de gasto mensal definido pelo administrador.

Colocar a sua chave (recomendado)

Sem cota de terceiros, prioridade no rate limit e privacidade do seu provedor. Leva 2 minutos e é gratuita na maioria dos casos.

O arquivo que importa

Todas as chaves ficam em .env.local, na raiz do projeto. Esse arquivo está no .gitignore e não é enviado ao GitHub.

# .env.local — nunca faça commit deste arquivo

# Provedor principal (recomendado)
OPENROUTER_API_KEY=

# Fallback de baixa latência (opcional)
GROQ_API_KEY=

# Alternativa ao OpenRouter (opcional)
GEMINI_API_KEY=

# Execução de código em sandbox (opcional, mas recomendado)
E2B_API_KEY=

# Só necessário para login e banco de dados (fase 2)
DATABASE_URL=
AUTH_SECRET=
ENCRYPTION_KEY=

Depois de editar, reinicie o servidor: variáveis de ambiente só são lidas no boot.

OpenRouter

GrátisRecomendado

Um único cadastro dá acesso a 20 modelos gratuitos com suporte a ferramentas. É o provedor padrão do agente e o que recomendamos começar.

  1. 01

    Crie a conta

    Acesse openrouter.ai e entre com Google ou GitHub. Não pede cartão de crédito.

  2. 02

    Gere a chave

    Vá em Keys → Create Key. Dê um nome (ex.: nexora-forge) e confirme. A chave aparece uma única vez — copie na hora.

    A chave começa com sk-or-v1-…

  3. 03

    Cole no arquivo .env.local

    Na raiz do projeto, crie ou edite o arquivo .env.local e adicione a linha abaixo.

    OPENROUTER_API_KEY=sk-or-v1-sua-chave-aqui
  4. 04

    Reinicie o servidor

    Variáveis de ambiente só são lidas no boot. Pare o processo (Ctrl+C) e rode de novo.

    npm run dev
  5. 05

    Confirme

    Abra /api/status no navegador. O campo ai.openrouter deve estar true.

    {"ai":{"openrouter":true}}
Abrir openrouter.ai/keys ↗OPENROUTER_API_KEY

Privacidade: Nos modelos gratuitos, a OpenRouter e os provedores podem usar seus prompts e respostas para treinar modelos. Se o conteúdo for sensível, use uma chave paga.

Groq

Grátis (free tier)

Respostas muito rápidas. Entra como segundo da fila: se a OpenRouter bater rate limit, o agente continua funcionando por aqui.

  1. 01

    Crie a conta

    Acesse console.groq.com e faça login com Google ou GitHub.

  2. 02

    Gere a API key

    Vá em API Keys → Create API Key. Copie o valor gerado.

    A chave começa com gsk_…

  3. 03

    Adicione ao .env.local

    É opcional. Sem ela o produto funciona, mas fica sem o fallback.

    GROQ_API_KEY=gsk_sua-chave-aqui
  4. 04

    Reinicie

    Mesma regra: variável de ambiente só vale depois de reiniciar o servidor.

Abrir console.groq.com/keys ↗GROQ_API_KEY

Privacidade: O free tier tem limites por minuto e por dia. Para uso intenso, é preciso plano pago.

Google Gemini

Grátis (com limites)

Modelos fortes em código. Útil quando você quiser mais qualidade que os modelos gratuitos da OpenRouter.

  1. 01

    Abra o AI Studio

    Acesse aistudio.google.com/apikey com sua conta Google.

  2. 02

    Crie a chave

    Clique em Create API key e escolha um projeto. Copie a chave gerada.

    A chave começa com AIza…

  3. 03

    Adicione ao .env.local

    Opcional. Se o provedor Gemini não estiver implementado na sua versão, use OpenRouter — é o caminho recomendado.

    GEMINI_API_KEY=AIza_sua-chave-aqui
Abrir aistudio.google.com/apikey ↗GEMINI_API_KEY

Privacidade: No free tier do Google, o conteúdo enviado pode ser usado para melhorar os produtos deles. No tier pago, isso não acontece.

E2B (sandbox)

Grátis até o limite

Sem ela, o agente cria arquivos mas não executa comandos. Com ela, o código roda de verdade numa microVM isolada — inclusive npm install e build.

  1. 01

    Crie a conta

    Acesse e2b.dev e entre com GitHub. O plano gratuito inclui créditos iniciais.

  2. 02

    Gere a chave

    No dashboard, vá em API Keys → Create Key e copie.

    A chave começa com e2b_…

  3. 03

    Adicione ao .env.local

    Depois de reiniciar, o status muda para “sandbox E2B” e o agente passa a executar comandos.

    E2B_API_KEY=e2b_sua-chave-aqui
Abrir e2b.dev/dashboard ↗E2B_API_KEY

Privacidade: A sandbox é cobrada por segundo de execução. O projeto já limita a 15 minutos por sessão para não haver gasto surpresa.

Perguntas frequentes

Minha chave fica segura?+

No seu computador, ela fica apenas no arquivo .env.local, que está no .gitignore e nunca vai para o GitHub. No servidor, fica em variável de ambiente e jamais é enviada ao navegador — a interface só recebe os 4 últimos caracteres, para você saber qual chave está ativa.

Preciso de cartão de crédito?+

Não. OpenRouter, Groq e o free tier do Gemini funcionam sem cartão. O E2B dá créditos gratuitos iniciais. Só há cobrança se você optar por planos pagos.

Posso usar mais de uma chave ao mesmo tempo?+

Sim, e é o recomendado. O agente tenta na ordem: OpenRouter → Groq → Gemini. Se um falha por limite ou erro, o próximo assume sem você perceber.

Quanto custa rodar isso?+

Com os modelos gratuitos da OpenRouter, o custo de IA é US$ 0 — confirmado com requisições reais. O E2B cobra por segundo de sandbox ativa, e o projeto limita a 15 minutos por sessão.

E se eu não quiser configurar nada?+

O site funciona como vitrine sem chave nenhuma. Mas a página Criar só gera sites se houver pelo menos uma chave de IA configurada — a barra de status no topo mostra o que está ativo.
